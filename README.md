# My Portfolio Website

This repository contains the source code for my personal portfolio website.

A modern, animated portfolio showcasing projects and skills, built with React, TypeScript, Vite, GSAP, and Three.js.

![Portfolio Preview](public/images/preview.png)

## Tech Stack

- React
- TypeScript
- Vite
- GSAP
- Three.js
- WebGL

## Local Development

1. Install dependencies:
```bash
npm install
```
2. Start the development server:
```bash
npm run dev
```
3. Build for production:
```bash
npm run build
```
4. Preview the production build:
```bash
npm run preview
```

## Notes on GSAP Plugins

This project currently uses trial/plugin setup choices for animation tooling. For production hosting with Club GSAP plugins, refer to the official installation guide:
https://gsap.com/docs/v3/Installation/
